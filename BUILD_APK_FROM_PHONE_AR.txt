بناء APK عبر GitHub من الهاتف فقط
1) أنشئ حسابًا/سجّل الدخول إلى GitHub.
2) أنشئ مستودعًا جديدًا (New repository) واجعله Private إذا أردت.
3) ارفع محتويات مجلد الباحث_العقاري_مشروع_اندرويد إلى جذر المستودع، بما فيها مجلد .github. إذا لم يظهر .github في مدير الملفات، فعّل إظهار الملفات المخفية أو ارفع المشروع من ZIP عبر المتصفح مع التأكد أن المجلد .github موجود في المستودع.
4) افتح تبويب Actions، اختر Build Android APK، ثم Run workflow.
5) بعد نجاح التشغيل، افتح نتيجة التشغيل (workflow run)، ثم Artifacts ونزّل albahith-al-aqari-apk.zip.
6) فك ضغط الملف، وستجد app-debug.apk لتثبيته على الهاتف.
ملاحظة: هذا المشروع المصدر وليس APK جاهزًا. البناء السحابي يحتاج حساب GitHub وتنفيذ الخطوات أعلاه. لم يتم اختبار APK الناتج بعد.
